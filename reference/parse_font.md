# Parse figlet fonts

Parse figlet fonts

## Usage

``` r
parse_font(path = "inst/fonts/basic.flf")
```

## Source

[http://www.jave.de/figlet/figfont.html](http://www.jave.de/figlet/figfont.md)

## Arguments

- path:

  The font path.

## Value

A named list which every elements is a character in the figlet font.
